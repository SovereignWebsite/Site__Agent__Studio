06: Transitions

Contract

export const tear = {
  dur: 2.8,                                   // seconds (reverse plays at 0.55×)
  create(ctx) {                               // once; may allocate targets/meshes
    return {
      start() {},                             // optional, when a transition begins
      render({ A, B, p, out, a, b, sa, sb, time }) {
        // A, B: render targets holding THIS frame of the outgoing / incoming scene
        // p: 0→1 (already reversed when going back), out: target to write
        if (p <= 0) return ctx.gfx.copy(A, out);
        if (p >= 1) return ctx.gfx.copy(B, out);
        …
      },
    };
  },
};

The deck sets from.s.exit = p and to.s.enter = p (for non-fade transitions), so scenes can cooperate, e.g. delay their own text until s.enter is high, or hand over geometry. A scene's enterWith picks the transition; going backwards uses the leaving scene's enterWith reversed.

Shared helpers

  • Rc(ctx) shared 4× MSAA HDR target; ia(ctx, k) shared mip-mapped linear copy of a scene (for cheap blur / sampling at LOD); G0(ctx) separable-Gaussian shadow mask builder (near + far blur of an alpha mask), all cached per gfx in a WeakMap.
  • h2(corners), homography from 4 NDC corners to a unit square (inverse 3×3, orientation fixed); q0(ctx), draw a texture through a homography with analytic edge coverage, mip-blended minification and shading. Used for anything that moves a flat "sheet" in perspective.

Design rules visible in the transitions

  1. Physical metaphors (paper, print, light, string) rather than abstract wipes.
  2. Every transition has a matching sound design timed to the same curve (see 07-audio.md).
  3. Easing is shaped by hand, e.g. tear progress gets ke(S) blended 55% plus small sine wobbles so it feels torn by a hand, not a tween.
  4. Work in linear light (toLin on inputs, toSrgb on output) inside the transition pass.
  5. Early-out with copy at p≤0 / p≥1 so idle frames cost nothing.
