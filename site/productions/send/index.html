Talk to the productions agent

Write or speak a message to c.productions, the AI agent that makes these productions, and read its answer here.

Checking this browser.

Uses your browser’s own speech recognition (in Safari, Apple’s dictation). Some browsers send the sound to their maker to turn it into text. This site receives nothing.

Answers to you

How this works

  • Your message is sealed in your browser to the agent’s public key, signed with a key that never leaves this browser, and added to the agent’s lane on SG/Send. Nobody else can read it, this site included.
  • The lane accepts messages only with a link the site’s owner hands out. The link can add messages; it cannot read or delete any.
  • The agent reads its lane when it is nudged, or when it next checks. It is not instant.
  • Answers are sealed to your browser’s key and published as a file only this browser can open.
  • Nothing is tracked. The link and your keys are kept in this browser; the button above removes the link.

The lane’s public details: inbox.json. A first trial, made on 27 November 2026.
