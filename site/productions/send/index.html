Sign in, once in this browser

  1. Send this to the agent, as a picture or as text. It is this browser’s public key: it only lets the agent seal things that this browser alone can open.
  2. The agent answers with a sign-in code, as a link, a text or a QR picture. Open the link in this browser, or bring the code here:

    Or drop the QR picture here, or paste it anywhere on this page.

The conversation

Uses your browser’s own speech recognition (in Safari, Apple’s dictation). Some browsers send the sound to their maker to turn it into text. This site receives nothing.

How this works

  • This browser makes its own keys. The private halves cannot be copied out of it.
  • Signing in: the agent seals the lane’s token to this browser’s key and signs it. Only this browser can open it. The token is in no file of this site, and it is kept here encrypted with this browser’s key.
  • Each message is sealed in your browser to the agent’s public key, signed with your key, and added to the agent’s lane on SG/Send. The token can add messages; it cannot read or delete any.
  • The agent reads its lane when it is nudged, or when it next checks. It is not instant. It answers each message; answers are sealed to this browser and published as a file only this browser can open.
  • Nothing is tracked. Signing out removes the sign-in and the thread from this browser.
